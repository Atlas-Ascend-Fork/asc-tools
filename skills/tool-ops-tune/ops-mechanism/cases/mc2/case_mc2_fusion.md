# 案例卡：MC² 通算融合（R 值五档驱动配平 — 反例警示样本）

- **算子类别**: communication / MC²（matmul_all_reduce 类）
- **DSL**: Ascend C + SHMEM
- **类型**: 非 PR（社区文章）+ 内部调优实战综合
- **来源可信度**: D（二手来源，仅作线索与背景）——**本卡价值在方法论示例而非数字**
- **来源链接**: 社区文章（端到端 1.3x–1.5x 区间报道）+ MC² 通算融合调优实践文档
  （**验证日期: 2026-10**）
- **瓶颈证据**: 隔离测试 R 值实测跨 0.3 ~ 9.8（30 倍区间）——R 不是常数，随 shape/量化/
  rank 数剧烈变化，每 case 必须实测，禁止沿用上一次的 R
- **优化机制**: Local Matmul（首选，不依赖 R）→ R 驱动配平方向（R<1 计算掩盖通信 /
  R>1 通信掩盖计算）→ 膨胀控制（最小化瓶颈方膨胀）
- **原文性能数字**: 端到端 1.3x–1.5x（D 级，不作预期收益依据）
- **适用范围与警示**:

  - ⚠ 跨 rank 取 max 口径：用平均口径报告会系统性高估收益。
