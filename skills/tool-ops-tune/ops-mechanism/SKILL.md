# 优化机制库与案例证据库（mechanism）

> **本子域知识资产（机制卡 / 案例卡 / 索引 / 回灌脚本）随「优化卡片知识」PR 交付**，
> 当前为骨架占位——SKILL.md 先行声明消费时机纪律与路由契约，供判定引擎
> `mechanism_refs` 字段的前向引用对齐。

## 消费时机纪律（渐进式披露）

**判定之后才加载**。没有 verdict 证据时禁止先加载机制/案例猜瓶颈——证据先行是
判定质量与上下文预算的双重保障。

## 路由契约

- 判定引擎每条 HIT 规则携带 `mechanism_refs`（指向本子域 `references/optimize/`
  下机制卡路径）；主 agent 按 findings 逐张加载（≤3 张候选方案卡）；
- 机制卡八要素与案例卡 A-E 证据分级的书写规范见套件根 `docs/知识库规范.md`；
- 无同型案例的降级策略：证据链 + 机制卡驱动，实施细节自行推导并提高验证强度，
  报告标注「无同型案例」，本次证据沉淀为 E 级案例候选。
