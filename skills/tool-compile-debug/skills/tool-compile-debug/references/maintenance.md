# 源码维护与发布

开发仓在`harness/engine`修改确定性工具、`harness/skill`修改技能与参考、`harness/installer`修改外层安装器与说明、`harness/dependencies`修改依赖锁；执行构建生成双层交付树（外层安装包装与测试、内层纯净运行包），禁止手改生成副本。独立托管或合入宿主仓时执行外层`tests/`整包测试和上游CI。

领域知识归cannbot-knowledge，本包不再生成API分片或维护版本/SoC表。升级知识依赖须审核commit、两个consumer入口、查询契约、治理结构及安装负例；不能让旧实验跟随开发锁更新。

发布前运行包内pytest/unittest、脚本扫描、链接与结构检查，并按目标仓当前CI配置核验。可写副本连续测试两轮，不通过清缓存掩盖污染。真实Linux验证安装、技能发现、索引预检及实际查询，再核原目标编译链；结果按执行证据记录。

技能元数据版本是唯一产品版本来源。知识checkout、环境、模型及构建记录单独绑定；安装回执不代替修复或真机结果。
