# research_items — 编译器 bug / 指令级研究项

## 基本信息

| 属性 | 值 |
|------|---|
| 异常编号 | research_items |
| 异常类型 | 编译器 bug / 指令级（未确认） |
| 错误码 | 无 / 不确定 |
| 类别 | static_preventive |
| 性质 | 探索型 |
| 覆盖条目 | 研究项 ~10：L129 / L139 / L140 / L141-L146 / L157 / L162（不计入 57 条确认不可复现） |
| 状态 | **未确认**（"从未尝试"或"研究项"范畴） |
| 报错模式 | 未知 / 需二进制手段 |

## 候选检测方向

| 文档行 | 错误特性 | 候选检测建议 | 预期成功率 |
|--------|---------|-------------|-----------|
| L129 | VMS 输入未排序 | 运行时检查 Sort API 返回值 | ~5% |
| L139 | VLOOP 内层指令数 > 外层 | 编译器应拒绝生成；静态检查循环嵌套深度 | ~5% |
| L140 | VLOOP 嵌套数超硬件限制（4） | 同上（静态检查循环嵌套深度） | ~5% |
| L141 | VEC VF 内 SIMT 指令参数非法 | 二进制版本校验；运行时监控 VEC VF 异常 | ~5% |
| L142 | VEC 当前版本不支持的指令 | 二进制版本校验 | ~5% |
| L143 | VF 的 PC 溢出 | 二进制校验 | <5% |
| L144 | CCU 请求 payload 非法配置 | 运行时监控 | ~5% |
| L145 | CCU 请求 payload 未定义 | 运行时监控 | ~5% |
| L146 | VEC 执行 ccu 请求超时 | RTS 配置确认 | 不确定 |
| L157 | DVG STACK underflow | 静态检查 SIMT push/pop 配对 | ~10% |
| L162 | SIMT join/end 不一致 | 编译器应保证 warp 统一 join/end | ~5% |

> 这些错误需要二进制/指令级手段或属编译器 bug 类，AscendC 代码层不可控。**尚未经实机确认**，属于"从未尝试"或"研究项"范畴，**不计入** 57 条确认不可复现总量。

## 关联异常

- 编译器版本升级可能修复 L129/L139/L140/L162
- L157 与 **dvg_stack_overflow**（runtime）相关（DVG stack 操作）

## 检测执行指引

- **未确认条目**：仅记录候选方向，不参与规则匹配
- diagnose Step 0：不主动输出；仅在用户显式查询"未确认条目" / "研究项"时返回候选方向
- 优先级：仅查询时可见
