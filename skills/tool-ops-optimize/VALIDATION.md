## 用户提供的历史硬件实验

下列数据摘自用户提供的《APROF Skill 性能分析与持续优化能力交付验证报告
Vector 专题 v0.3》（2026-10-23）。报告对应历史 graph-base 1.3.0，
Maximum 批次使用 runtime 0.8.0，近期 Vector15 批次使用 runtime 0.8.2。
数据用于说明已有方法与工作流的能力背景，没有重新绑定到本次 1.3.2，
也没有在本次接入中重做测量或独立核验其全部原始归档。

- Maximum INT32 行广播：输入 `[2,3,5,1024,256]` 和 `[1,1,1,1024,1]`，
  原实现 14539.650 μs，R15 研究实现 53.842 μs，直接比较 270.04 倍，HAP 0.377067。
  展示广播结构重组、批量搬运和向量计算。
- Transpose FP32：输入 `[2,511,7,127]`，`perm=[0,2,1,3]`，
  原实现 1442.922 μs，最终实现 22.582 μs，直接比较 63.90 倍，HAP 0.477283。
  主要行组搬运改进来自 R2，最终 R3 继承该路径。
- Mish FP16：输入 `[8192,8192]`，原实现 843.456 μs，候选 441.480 μs，
  直接比较约 1.91 倍，HAP 0.618906。展示类型感知容量核算和双物理槽流水。

报告的 Maximum 持续优化专项保留固定 20 组 workload。R15 研究实现直接对初始实现
的几何平均加速为 5.4934 倍，17/20 组 HAP 达标；工程保留版本仍是 R10，
R15 相对实际父本 R13 的增量判定为 inconclusive。历史完整机器交接还有未准入项，
不能据此声明本版正式交接已通过硬件验收。

报告设备为 Ascend910_9392（910C/A3），CANN 9.0.0；采用 5 次预热、
20 次逐轮清 L2 的完整设备调用，按全部目标 Task 求和后取中位数。
不同历史批次的稳定性协议分别保留。HAP 使用冻结的 910B2 参考，
不是 910C 硬件利用率；精选成功 workload 不代表整体通过率或任意输入的收益。
