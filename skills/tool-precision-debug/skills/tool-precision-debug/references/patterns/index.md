# 故障模式与案例

本目录沉淀容易出现精度异常的机制、算子特有风险和历史诊断经验。结合实际计算链、标记的敏感点与失败现象，查阅相关经验，形成有依据的候选并开展低成本验证；不必等到已有可疑区间才使用。

系统定位取得新观察后，再针对异常环节核对相关经验。现象相似不等于根因相同，使用时检查当前输入、源码与环境是否满足适用条件。

| 入口 | 什么时候读 |
| --- | --- |
| [通用故障模式](mechanisms/index.md) | 计算链涉及类型转换、累加、地址、缓冲复用、同步、尾块等敏感点，核对常见错误机制及触发条件 |
| [算子特有风险](operators/index.md) | 根据算子族识别容易出错的计算阶段及诊断经验 |
| [历史案例](cases/index.md) | 对照具体输入、错误现象与排查过程，借鉴关键观察和验证方式 |

## 按症状选择检查

下表将常见残差直接连到正文。选择与当前计算链吻合的入口，复用已有输入做一项有区分力的检查；不必遍读所有页面。相同症状可能有不同根因，检查结果再决定是否转向。

| 当前症状或计算结构 | 相关章节 | 可先做的检查 |
| --- | --- | --- |
| Log/Atanh 近零误差突增，输出变零 | [近零逐步对照](mechanisms/accumulation-order.md#atanh-近零的逐步对照) | 保存 `x`、舍入后的 `1±x` 和输出，区分输入量化、加法吞没与函数近似 |
| 加入多项式分支后，极大有限输入反而出 NaN | [未选分支与乘零混合](mechanisms/special-values.md#未选分支也可能污染结果) | 分别保存两支的类别，检查未选支路是否先溢出，再经乘零传播 |
| Exp/Cosh 稳定改写后，只剩有限/Inf 交界失配 | [分类边界映射](mechanisms/special-values.md#有限与-inf-分类边界) | 在实际输入 dtype 的相邻可表示值上比较变换、Exp 和最终乘法 |
| 分块 Norm 局部正常，合并统计或分母错误 | [状态更新时序](operators/normalization.md#统计状态的原地更新时序)、[迭代预算](operators/normalization.md#倒数与开方的迭代预算) | 用两个不等长、均值不同的块核对旧/新状态；统计正确后再查近似分母 |
| 自适应平均池化在矩形、非整除或维度 1 上失败 | [小窗口对照](operators/reduction.md#自适应平均池化的小窗口对照) | 手列一个输出的半开窗口、坐标、count 与累加 dtype，先核对一个窗口 |
| Softplus 首 repeat 正常、后段重复，或极负区小量归零 | [按残余症状查案例](operators/softplus-v2-grad.md#按残余症状进入案例) | 分别进入已有 repeat/mask 或 subnormal 支路，比较具体 lane 与首次归零步骤 |
| SIMT/RegBase 等一条实现修好，另一 shape/dtype 仍失败 | [跨实现操作例](mechanisms/algorithm-parameter-contract.md#跨实现的小量放大对照) | 将同一数值条件对应到各可达实现，核对真实分派与各自中间量 |
| 融合算子逐元素通过、只有 bias 超差，或主尾列类别分叉 | [GRU bias 案例](cases/thnn-fused-gru-bias-reduction.md) | 保留归约前未收窄值，核对当前参考的求和语义、主尾列与合并层级 |

GRU 等历史案例先匹配当前需求与参考版本；要求已改变时，借鉴观察方法，不照搬旧求和树。修复后出现新的分段漏写时，再查[可变计数副作用](mechanisms/tiling-tail-state.md#可变计数被消费后续输出漏写与清零不完整)。

快速验证的范围与退出条件见 [SKILL.md 阶段 3](../../SKILL.md#阶段-3定位问题与验证根因)，实验及系统定位的操作方法见 [diagnosis](../diagnosis/index.md)。接口参数与产品支持使用 `ascendc-api-knowledge-query`，算子实现示例使用 `knowledge-query` 查询；经验中的 CANN/NPU 或输入条件只覆盖正文明确说明的范围。
