# 尾块有效区与旧状态：先证明本轮写入

最后一个 tile、最后一个 core 或条件分支后才出现旧值、零值或前一轮图样时，先把问题写成“本轮 producer 是否向消费者要读的有效 region 写过值”。本页用状态模型说明排查方法，实际接口行为按当前产品和版本核对。

## 从症状建立竞争候选

冻结当前 shape、分派、输入、产物身份和首个失配坐标，再记录该坐标所属 `(core, row, tile, stage)`、逻辑有效区和物理 padding。把生产边和消费边展开到 `(物理根/基址, offset, 有效范围, generation)`：若本轮 producer 写入不足以覆盖 consumer 的首次读，则同步文本是否配对不能解释内容正确性。

尾块异常至少有四个竞争候选：Host 与 Kernel 对有效长度不一致；mask、搬出长度或地址把无效 lane 当成结果；本轮零工作量或跳过分支没有写目标 region，消费者读到了上一 generation；以及 buffer 在消费者结束前已被复用。它们可同时出现，因此不要用“加一条 Wait 后变好”合并结论。

一个有限状态模型给出可复现的触发器：前一完整物理 tile 为 `[1, 2, 3, 4]`，本轮只产生两个有效值 `[10, 20]`。模型中的写后物理区为 `[10, 20, 3, 4]`，所以逻辑 consumer 应以 `valid=2` 得到 sum `30`、mean `15`；若错误地把整个物理 tile 都读进来，则得到 sum `37`、mean `37/4`。这不是设备内存或某个 DataCopy 的观察，而是把“本轮只写有效前缀”和“消费者误读整块”分开的精确有限对照。

## 两个互斥的最小路径

选择同一地址、同一输入和同一同步对象，只改变使 producer 做最小合法正工作或零工作/跳过的当前谓词。每次在 producer 前后记录目标有效区的值和 generation，并在 consumer 的第一次读前保存同一 region。正工作路径更新正确有效区而零工作路径不更新时，支持“未写本轮 region”；两条路径均已写却仍从边界开始错误时，转查 mask、地址映射或生命周期。

对无效 lane 另设探针：使有效 lane 和 padding 的标识不同，再按当前输出约定只比较有效区。上例将后两个物理位置置零时，全范围 sum 恰好也为 `30`，会掩盖 sum 的错误；但全范围 mean 仍为 `15/2`，不等于逻辑 mean `15`。置成 `[100, 200]` 时，错误全范围 mean 变成 `165/2`。因此仅填零且一个 sum 通过不足以证明有效区正确；若当前算子约定允许中性 padding，它能否成为实现的一部分仍取决于约定，而 mean 必须使用实际 valid count。物理 padding 本身不是数学输出。

## 对照与否证

一 tile、恰好整除、余一个元素和最大合法尾块必须成对运行；同时保留一个会复用 slot 的多 tile control。若只在多 tile 才出现前一轮的标识，优先审计 slot 的最后读者与下一次写入；若单 tile 的尾块已错而 region 从未复用，优先审计有效长度和地址。改变 tile 大小、核数或 buffer 数会同时改变分派和调度，只能作为候选实验，不能单独确认 UB 容量或同步根因。

修复应只让实际 producer 覆盖本轮有效 region，或让消费者只读取约定允许的有效区；随后回放原失败、边界两侧、连续重复、不同 core 所有权和实际会复用 slot 的路径。无法观察到地址、循环谓词或产物采用时，保留 `UNKNOWN`，不把稳定的旧值图样写成已确认根因。
