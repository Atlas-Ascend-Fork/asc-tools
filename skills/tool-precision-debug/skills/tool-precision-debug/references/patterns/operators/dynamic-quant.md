# 动态量化：统计范围、scale 角色与舍入边界

DynamicQuant / DynamicQuantV2 精度异常先沿“分组与可选平滑 → 极值统计 → 量化参数 → 浮点映射 → 舍入/饱和 → 输出与参数回写”定位首次分叉。逐输出检查 y、scale、offset；y 通过不能证明辅助参数正确，辅助参数误差很小也不能证明整数输出不变。

本页提供固定来源支持的算子语义与调查方法。当前任务的合法输入、零范围处理、舍入和特殊值规则仍以其公开需求为准；不要把某个库实现的 epsilon、tiling 常量或输出类型范围复制成通用约定。

## 先确认 scale 和 offset 表示什么

`ops-nn` 的 DynamicQuant 定义每个 token 的对称量化，DynamicQuantV2 还定义非对称量化。若存在平滑系数，统计量和量化应基于算子定义的平滑后输入 u；按组选择平滑系数时，组映射也属于计算链。

| 路径 | 固定来源中的计算关系 | 优先核对 |
|---|---|---|
| 对称量化 | s = max(abs(u)) / Q，y = round(u / s) | 返回的 s 是反量化步长；实现内部的乘数 k = 1/s 与 s 角色不同 |
| 非对称量化 | s = (max(u) − min(u)) / (q_max − q_min)，z = q_max − max(u)/s，y = round(u/s + z) | offset 的符号、单位和加入位置；上下端点是否映射到对应整数端点 |

这里 Q 和 q_min/q_max 来自目标输出约定。来源的 INT8 路径采用 Q=127、q_min=−128、q_max=127；其他格式应读取其自身定义。全零或常量行使 s 的普通公式退化，不能自行决定输出零、加 epsilon 或返回某个固定 scale；先查任务对该输入的规定。

先用局部 oracle 分别比较极值、s、内部 k、z、舍入前浮点值和最终编码。`s = a/Q` 与 `s = 1/(Q/a)` 在实数域等价，FP32 逐步求值未必相同；是否允许差异由输出比较约定决定。变量名 `scale` 无法说明它在某段代码里表示步长还是乘数。

## 从现象选择区分实验

| 观察 | 有区分力的下一步 | 结果边界 |
|---|---|---|
| y 大体正确，scale 系统性偏离 | 固定极值和元素分布，逐段核对对外 s 与内部 k；加一组两者不会互相掩盖的极值 | 支持参数角色问题，不能因此排除尾部或其他输出错误 |
| 非对称路径整体偏移 | 同一行保留最小/最大端点及中间值，检查 z 的单位、符号、舍入和饱和位置 | 端点检查可发现仿射关系错误，不能代替舍入边界回归 |
| 少量整数差 1，scale 误差很小 | 选择映射后靠近半整数的输入，保持 shape、极值、dtype、tiling 不变；对比除法/倒数、乘法、Cast 前后的实际值 | 小的浮点扰动跨过舍入分界即可改变整数；不能由整数差 1 直接认定 Div 的误差方向 |
| 最后几行或不同分核后异常 | 将失败行回映到 core、批内行、全局行及三路输出地址，核对每个合法行的计算和写回是否发生 | 先区分行覆盖、统计有效区、输出地址和算术；不要先扩大容差 |
| padding 或尾轴变化后 scale 改变 | 固定所有有效元素，只改变无效区哨兵与尾轴分块，比较参与极值的元素集合 | 极值被无效区污染与输出尾行漏算是不同候选，需要不同观察点 |

量化边界 probe 应复用正式输入量化与 materializer。想测试浮点映射的某个半整数邻域时，先确认输入经 FP16/BF16 存储后该邻域仍然存在，并且没有顺带改变行极值。若修改除法路径后恢复，还要确认内部参数真实变化及新路径采用；仅在 Host 用 k±1 ULP 重算，只能说明一种候选解释与输出相容。

## API 路径与最终验证

向量除法接口、精度配置以及 Vector/Scalar 交接的同步按实际 profile 查询 API。不能把“向量换标量后样本通过”概括成标量除法在所有输入上正确舍入，也不能为了精度把应由设备完成的量化转到 Host。

原失败恢复后，按实际改动覆盖对称/非对称、参数退化、舍入/饱和边界、行与列尾部，以及可选平滑/分组中实际存在的路径。比较 y、scale、offset 的各自约定与必要联合关系；已有可构造的合法残差优先补最小 probe，再决定是否扩大回归。

## 使用范围

本页提供算法语义与实现分叉；具体工程仍须完成自身的 NPU 回归。半整数邻域的放大关系采用 FP32 数值模型，不代表某条设备除法指令的误差界。
