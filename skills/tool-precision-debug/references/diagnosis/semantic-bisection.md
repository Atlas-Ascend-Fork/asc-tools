# 语义二分定位

同一依赖链上已有可比、稳定的 PASS/FAIL 端点，且有依据支持局部单调假设时，用二分减少中间观察。目标是缩小当前判据的正常→异常转变区间；缩区本身不证明其他代码正确。

## 前置条件

先确定本轮要搜索的判定边界，再核对：

- **数据依赖对应**：按失败输出的真实生产者→消费者关系排列观察点，关联同一输入、相关逻辑数据、分片/轮次和观察面。多分支汇合时核对相关输入与共享状态，不能用一条支路 PASS 代表全部上游正常；具体见[观察点设计](checkpoint-design.md#选择位置)。
- **判定可比**：参与缩区判断的点有适用的独立参考和判据。搜索累计差异时，各点使用同一原始输入推导的阶段参考；基于实际阶段输入的局部重放只检查本段，不能混成累计正常端点。不变量通过也只覆盖该性质，参考选择见[局部对照](checkpoint-design.md#准备局部对照)。
- **观察有效且边界稳定**：已有可信 PASS 前端和 FAIL 后端，复用适用的重复观察。有漂移迹象时先按[复现性方法](reproducibility.md#判断稳定性)核对；单次有效 FAIL 仍保留，但不证明边界稳定。`AMBIGUOUS`、不可比或已知受扰动而不能代表当前目标的点不作端点。
- **单调假设有依据**：结合该段计算和判据，说明为何预计形成 `PASS ... PASS | FAIL ... FAIL`。重复结果稳定不保证沿链单调，已测点没有倒序也不证明未测点没有倒序。存在抵消、截断、覆盖恢复或路径切换疑点时，先补能区分这些情况的观察，不据后段 PASS 排除前段。

无需先测完整条链；把单调性作为有依据、可被新观察推翻的假设。条件不足时仍可按当前疑点选点，暂不作大范围二分缩区。

## 执行

1. **确定当前范围**：以已观察的 PASS 点 `L` 和后续 FAIL 点 `R` 为端点，保留两端结果、参考依据、源码位置和对应数据。
2. **选择中间点 `M`**：在相关依赖链的当前区间内，选接近中部、语义清楚且容易取得参考的位置，同时考虑采集成本和扰动；不按源码行数划半。
3. **取得有效比较**：优先复用已有实际结果和阶段参考，缺观察时按[检查点设计](checkpoint-design.md)补充，只采集当前判定所需的数据。
4. **更新端点**：前提仍成立时，`M = PASS` 则更新 `L = M`，`M = FAIL` 则更新 `R = M`；无有效判定或结果动摇原假设时先停下缩区。记录新范围及暂不继续采样其他部分的依据，再决定下一观察。

这里缩小的是所选判据的转变区间。较早的偏差可能尚在容差内，到后段才被放大至超差；中点 PASS 不能自动排除上游致错代码，FAIL 也不证明后段没有其他问题。需要解释传播与局部新增差异时，按[逐层分析](progressive-error-analysis.md#区分传播与新增偏差)继续。

### 一个完整例子

假设同一有效切片 `float32 [1,2,3,4]` 应原样经过以下搬运链，各点均按已确认的元素映射与原输入作精确比较。本例假设执行和观察稳定，且差异一旦出现不会在后段恢复；真实任务仍需核对此条件，不能把所有搬运链都视为单调。

```text
K0 入口 → K1 搬入后 → K2 临时缓冲 → K3 搬出前 → K4 输出
```

| 已有或新增观察 | 当前范围 | 下一步 |
| --- | --- | --- |
| K0 为 `[1,2,3,4]`，K4 为 `[1,2,30,4]` | K0 PASS → K4 FAIL | 选择中间点 K2 |
| K2 为 `[1,2,30,4]`，判为 FAIL | K0 PASS → K2 FAIL | 再观察 K1 |
| K1 为 `[1,2,3,4]`，判为 PASS | K1 PASS → K2 FAIL | 检查这段实际读取、偏移、长度和缓冲复用，形成具体候选 |

此时已有明确的代码检查范围，可以进入候选验证；K3 仍未测，不把预测写成实际 PASS/FAIL。若补充观察发现差异曾消失再出现，撤回受影响的缩区结论。

## 多轮记录

复用已有比较报告，在同一记录中更新已测点、当前边界和下一观察点；已有结果少、下一步清楚时直接分析，不另建固定格式的计划。轮数和点数按实际区分需要安排。

每轮取得比较后，重新核对可比性、稳定性、扰动和局部单调假设，再更新端点。比较报告和关键采集背景保留在[任务产物目录](reporting.md#任务产物目录)，未测点继续标为未测。

当前记录的两个端点之间没有已列出的观察点，不代表源码只剩一步或一个 API。区间已足以检查具体实现时就转入[假设验证](hypothesis-experiment.md)；仍包含多段未知计算时，再补有区分力的语义点，不为凑“相邻”覆盖全部节点。

**结束二分**：保留可信两端、区间涉及的代码和数据依赖、当前候选及下一项检查。已有证据足够时可直接确认相应机制，不强制再做实验。信息不足或观察冲突时，按原因补证或换观察；预算结束时交付已有缩区依据和未解决部分。

## 退出和降级

保留已有有效观察，按当前缺口选择下一步：

| 情况 | 下一步 |
| --- | --- |
| 同一条件下判定交替或错误位置漂移 | 按[复现性方法](reproducibility.md#判断稳定性)核对触发与运行条件，暂停依赖稳定边界的缩区 |
| 出现 FAIL 后再 PASS，或有累积、抵消、放大线索 | 重新检查单调假设，按[逐层分析](progressive-error-analysis.md)区分传播与本段差异 |
| 参考不独立、比较范围不对应或采集不完整 | 按[观察点设计](checkpoint-design.md)补具体缺口，或改观察其他可比位置，不把未知点当 PASS |
| 插桩改变原现象，或其影响不足以支持当前边界 | 按[观察有效性](checkpoint-design.md#判断观察是否有效)核对；保留本轮有效结果及其限制，不替代原程序基线 |
| 已有一个或多个有依据的候选 | 按[实验设计](hypothesis-experiment.md#实验设计)检查预测与实际联动，不为完成二分而增加无用观察 |

例如单核对照同时改变 tiling、GM 所有权或调度时，按组合观察解释，不能直接确认某条同步关系。二分缩区结果与根因判断分开，具体机制由源码、预测和有效观察共同支持。
