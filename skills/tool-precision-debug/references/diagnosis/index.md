# 诊断方法

本目录为[阶段 3](../../SKILL.md#阶段-3定位问题与验证根因)的低成本验证、系统定位和根因确认提供操作方法。先结合计算链与 [patterns 中的沉淀经验](../patterns/index.md)做有限初筛；未解决时通过观察点、二分或逐层分析取得新证据。初筛范围与转向条件以 SKILL.md 为准，方法按需读取，已有证据可复用。

| 当前问题 / 何时读 | 方法 | 适用条件与解释边界 |
| --- | --- | --- |
| 初筛已有候选，或系统定位后需要验证具体根因 | [假设与因果实验](hypothesis-experiment.md) | 选择有区分力且成本合适的检查；初筛无进展时转向系统定位，局部验证依据新证据展开 |
| 只知道最终输出错误，想从错误分布、首错坐标或错值缩小范围 | [错误分布与定位](localization.md) | 把错误对应到实际计算和数据流；空间分布或数值吻合不直接证明根因 |
| 不知道在哪里观察，或中间值缺少可信对照 | [观察点设计](checkpoint-design.md) | 按待区分的问题选择位置与执行实例，准备局部对照，根据有效观察推进到代码检查或实验 |
| 已有可比、稳定的正常/异常端点，且支持局部单调假设 | [语义二分](semantic-bisection.md) | 按数据依赖缩小判定边界；缩区不直接排除根因，前提动摇时补观察或换方法 |
| 误差累积、消失后重现，或不同阶段尺度难以比较 | [逐层误差分析](progressive-error-analysis.md) | 区分产生、放大与形态变化；后段误差大不等于根因在后段 |
| 需要筛选算术链、dtype 候选，或确认关键设备数值行为 | [数值对照与设备探针](numerical-modeling.md) | 区分验收参考、局部模型与设备观察，按有效对照结果推进代码定位 |
| 需要观察 Kernel 内部指定 Tensor 的值 | [DumpTensor 观察](dumptensor.md) | 在 Kernel 对应位置主动调用，确认数据就绪并控制插桩扰动；具体接口按目标环境查阅 |
| 比较规则不清、精确相等含义不明，或测试判定可疑 | [比较与验收](baseline.md) | 确认输出语义、参与比较的元素和实际判据，区分数值相等和逐位一致 |
| 失败不稳定、重编无变化、环境身份不明或当前未复现 | [复现同一个失败](reproducibility.md) | 现场、输入、产物与真实退出码集中在此核对；未复现不等于修复 |
| 不清楚输出角色、验收要求或实际计算链 | [算子建模](operator-modeling.md) | 从需求和真实路径建模，按需要核对执行与存储；测试列表不代替需求 |
| 开始定位或修复，需要保留关键事实或整理交付 | [报告指引与模板](reporting.md) | 随关键证据更新，按阶段产物整理结论、流程转向与缺口；末尾保留知识和工具的关键使用摘要，范围服从用户目标 |

需要形成或核对候选原因时，查看[故障模式与案例](../patterns/index.md)并核对适用条件；架构能力与硬件模型调用 CANNBOT `npu-arch` 技能查询，具体 API、调用语义及样例调用 CANNBOT `ascendc-docs-search` 技能查询。CANN 工具与调试 API 的使用入口见[工具选用](../tools/index.md)。
