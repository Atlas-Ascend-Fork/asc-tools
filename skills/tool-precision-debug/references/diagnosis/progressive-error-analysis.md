# 逐层误差传播分析

已有可比的阶段观察，误差逐步累积、放大、抵消，或出现 `PASS → FAIL → PASS` 时使用。本页帮助区分上游传入的差异与本阶段尚未解释的偏差，再选择下一步检查。

## 选择相关阶段与参考

沿失败输出的实际数据依赖选择相关阶段，优先复用已有输出和比较报告。核对输入、执行路径、轮次与有效区；Reduce、broadcast 或布局变化前后，按输入输出映射关联数据及完整依赖范围，不套用相同数字索引。具体见[观察点设计](checkpoint-design.md#对应到本次执行的数据)。

每个阶段使用匹配其公式、dtype、Cast、累加方式和必要求值顺序的局部参考与判据，见[局部对照](checkpoint-design.md#准备局部对照)。最终 golden 和容差不能直接套到所有中间量。缺最终 golden 时，可以依据已确认定义构造并核对独立局部参考；只有不变量时，结论限于该性质，不能据此排除整段计算。

固定输入下出现漂移时，按[复现性方法](reproducibility.md#判断稳定性)核对执行实例与采集条件，避免把不同轮次的变化拼成传播趋势。参考不适用、数据不可比或采集不完整时保留 `AMBIGUOUS`，补相应缺口；已有有效观察继续保留。

## 整理已有误差

按相关依赖链整理已有比较结果，保留参考依据和有效范围。根据疑点记录绝对误差、适用的相对误差、超差比例、特殊值、错误坐标和符号，缺指标注明，不要求全链采集。分开观察：

- 首个已观察到差异的点；
- 首个按该点判据验收失败的点；
- 幅度、符号、特殊值或错误位置发生变化的区间。

首次观察到差异不等于首次产生差异，未测区间内部仍未知。首次超差也可能只是更早的误差被放大。相邻最大误差的差值或倍率不能代表本段新增偏差，误差可能换位置或相互抵消；不据此给各阶段排最终贡献大小。

汇总已有报告中的误差变化、首次测得非零绝对误差及首次验收失败，位差可能没有非零绝对误差。没有指标或尚未测量的点保留缺口；表中相邻观测可能跨越未测阶段，不能据此认定它们在计算链中直接相邻，也不能仅凭趋势判定根因。

## 区分传播与新增偏差

需要判断偏差是否由本阶段引入时，准备可信的独立局部参考 `R`，按当前缺口取得以下对象。多输入、影响计算的属性和必要状态都应纳入参考，不能只重放其中一个输入。

| 对象 | 如何取得 |
| --- | --- |
| `actual` | 本阶段真实观察到的输出 |
| `R(x_obs)` | 将本阶段实际输入 `x_obs` 送入独立局部参考 |
| `R(x_ref)` | 可信参考输入 `x_ref` 经同一局部参考的输出；已有等价的阶段参考可复用 |

1. **比较 `actual` 与 `R(x_obs)`**：按该点适用的判据，检查真实输出能否由实际输入解释，是否还存在本段未解释的偏差。
2. **按需比较 `R(x_obs)` 与 `R(x_ref)`**：观察输入差异经过该阶段后怎样改变幅度、位置和类别，与实际现象核对。

只有 `actual` 和 `R(x_obs)` 时，仍可检查本段局部差异，但不能由这两项得出输入偏差的传播量。缺实际阶段输入或适用参考时，说明尚不能区分的部分；保留已有数值或不变量观察，不把拟合 actual 的模型当作独立依据。

尤其区分候选模型 `M` 与已确认语义的独立参考 `R`：`actual ≈ M(x_obs)` 只表示候选预测吻合，不能据此判为上游传播。一个反例是本段定义 `R(x)=x`，候选模型 `M(x)=2x`，实际输入与可信参考输入均为 `1`，实际输出为 `2`；候选完全吻合，但输入没有偏差，本段仍偏离独立参考。即使 `actual ≈ R(x_obs)`，也还需用 `R(x_ref)` 检查输入差异能否解释当前现象，再据此回查上游。

例如本段定义为 `y = 16x`，可信输入为 `1`，实际输入为 `17/16`，则 `R(x_ref) = 16`、`R(x_obs) = 17`：

| 实际输出 | 本例的局部差值 `actual - R(x_obs)` | 下一步 |
| --- | --- | --- |
| `17` | `0` | 输出差异可由输入传播解释，回查上游为何偏离 |
| `21` | `4` | 输入传播只能解释差异 `1`，继续调查本段剩余差异 `4` |

本例数值和运算在 float32 下可精确表示。一般浮点运算仍按已确认的舍入方式和局部判据比较，不套用精确相等要求。局部对照通过只覆盖当前输入和所选判据，不能证明上游或后续阶段正确。

## 解释尺度与形态变化

比较幅度时，保留原始误差，必要时再按有语义依据的阶段尺度归一，例如可信参考的范数或任务明确的动态范围。事先确定尺度的定义与计算范围；归一用于解释差异，不替换原验收阈值。不同语义阶段没有可比尺度时，不把归一数硬排成贡献大小。

某个参考元素为零，不代表整个阶段没有可用尺度。例如参考为 `[0, 1]` 时，第一个元素不能用自身参考值作相对误差分母，但参考的无穷范数仍为 `1`。只有所选尺度为零、不可用或缺少语义依据时，才将该归一结果保留为未知；继续观察绝对误差和特殊值类别，不临时加 epsilon 改变排序。

形态变化先按本段正常公式和坐标映射解释。正确的逐元素乘法，也能把全域微差变成仅在非零权重位置出现的差异；归约和布局变化同样会改变误差分布。因此尾部周期、符号或特殊值变化只是线索，形态不变也不能排除新增偏差。结合局部重放和源码，选择能区分当前解释的观察，不固定“形态变化优先、幅度其次”的顺序。

## 根据结果继续定位

| 有效观察或缺口 | 下一步 |
| --- | --- |
| 局部重放符合实际输出，输入差异可解释后续现象 | 回查上游差异来源；各段均符合局部语义而最终仍失败时，检查整个算法的累加精度、运算顺序和数值稳定性 |
| 实际输出仍偏离基于实际输入的局部参考 | 确认比较与采集有效后，调查本段计算、实际读取、状态、有效区和数据依赖，形成具体候选 |
| 误差在后段减小、消失或重新出现 | 检查抵消、截断、掩码或放大是否能解释变化，不能用后段通过回填前段正确 |
| 缺适用参考、实际阶段输入或可比观察 | 补最能区分当前疑点的一项，或继续不依赖该缺口的分析；不把未知点作为正常边界 |

有具体候选后，按[假设与实验](hypothesis-experiment.md#实验设计)检验预测并核对实际联动。需要继续缩区时，按[语义二分前提](semantic-bisection.md#前置条件)核对端点的可比性、稳定性及局部单调假设，一次误差跳变不足以证明未测区间单调。记录已解释的差异、尚未区分的部分和下一项检查，证据足够时收口，不为完成全链排名继续采样。
