## Description

Used together with the [--op\_params\_dir](../input_options/op_params_dir.md) parameter to count the number of operator information statistics JSON files in the directory specified by the [--op\_params\_dir](../input_options/op_params_dir.md) parameter.

## Related Parameters

Used together with the [--op\_params\_dir](../input_options/op_params_dir.md) parameter.

## Parameter Values

None

## Recommended Configuration and Benefits

None

## Examples

```bash
op_compiler -p <dump_dir> --count
```
