# --compile\_mode

## 功能说明

工作模式。可选。默认为纯编译模式，配置为tune为调优模式。简写为-m。调优功能自CANN 9.1.0版本起废弃，配置tune后调优模式不生效，自动切换为默认编译流程。

## 关联参数

无。

## 参数取值

取值支持配置为tune，自CANN 9.1.0版本起废弃，配置tune后调优模式不生效。

## 推荐配置及收益

无。

无。
